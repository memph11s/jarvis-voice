# Приватность Jarvis Voice

Этот документ фиксирует обязательные правила обработки данных в проекте. Они относятся и к текущей реализации, и к будущим изменениям. Публичность репозитория не влияет на приватность данных пользователя: исходный код открыт, а аудио, запросы и документы пользователя в него не попадают.

## Основные правила

### 1. Локальная обработка по умолчанию

- Речь распознаётся только локальным Vosk.
- Обычная диктовка не отправляется на внешние серверы.
- Вопросы к помощнику обрабатываются только локальной Ollama.
- Для Ollama разрешены только `127.0.0.1:11434` и `localhost:11434`. Любой внешний endpoint должен отклоняться кодом.

### 2. Аудио не сохраняется

- Микрофонный поток существует только в памяти во время обработки.
- Записи разговоров не создаются и не сохраняются.
- Аудио во время приветствия и ответов Jarvis отбрасывается, чтобы собственный голос не попадал в распознавание.

### 3. История отключена

- История разговоров и распознанного текста по умолчанию не ведётся.
- Каждый запрос к Ollama независим и не содержит предыдущие вопросы.
- Постоянную память можно добавлять только как отдельную функцию, явно включённую пользователем, с понятным местом хранения и возможностью полного удаления.

### 4. Приватные логи по умолчанию

- `JARVIS_PRIVATE_MODE=true` является поведением по умолчанию.
- В приватном режиме логи содержат только статусы: начало записи, запрос к локальной модели, получение ответа.
- Распознанный текст, вопросы, ответы, содержимое документов и секреты не выводятся в логи.
- Показ содержимого разрешён только при явном `JARVIS_PRIVATE_MODE=false`.

### 5. Временные файлы удаляются

- WAV-файлы, необходимые для локальной озвучки, создаются во временном каталоге и удаляются сразу после проигрывания.
- Временные файлы не используются как история или кэш разговора.

### 6. Никакой скрытой сетевой активности

- Нет аналитики, телеметрии, рекламных идентификаторов и фоновой отправки статистики.
- Нет скрытых проверок обновлений и обращений к внешним API во время обычной работы.
- Сеть используется при установке для скачивания зависимостей и моделей, а во время диктовки — только для локального Ollama при явной команде «спроси».
- Новые сетевые вызовы должны быть документированы, иметь понятное назначение и не включаться незаметно для пользователя.

### 7. Внешние действия только по явному намерению

- Jarvis вставляет текст в активное окно, но сам не отправляет форму и не нажимает Enter.
- Передача текста внешнему приложению или сервису, выполнение команд, изменение файлов и отправка сообщений требуют отдельной явной команды пользователя.
- Для необратимых или внешних действий нужно отдельное подтверждение.
- `--dangerously-skip-permissions` и аналогичный обход разрешений запрещены.

### 8. Минимум данных для новых функций

Перед добавлением функции нужно ответить:

1. Какие данные ей действительно необходимы?
2. Можно ли обработать их локально?
3. Где они хранятся и когда удаляются?
4. Попадут ли они в логи, ошибки, аналитику или тестовые снимки?
5. Понимает ли пользователь, когда данные покидают устройство?

Если локальная обработка возможна, внешний сервис не должен быть обязательным.

## Что находится за границей гарантии

- После вставки текстом управляет приложение, в которое он вставлен. Его собственные сетевые вызовы и политика конфиденциальности к Jarvis не относятся.
- Claude Code и Ollama могут скачивать модели отдельно от Jarvis. Во время обычной работы Jarvis не инициирует такие загрузки.
- При `JARVIS_PRIVATE_MODE=false` пользователь явно разрешает вывод содержимого в терминал.
- Системные голоса macOS, Windows и Linux могут иметь собственные правила и компоненты. Для строгой локальной работы предусмотрена Piper.

## Требования к изменениям

Любое изменение должно сохранять текущую диктовку и команды, если пользователь отдельно не решил их изменить.

Для функций, затрагивающих данные или сеть, нужны тесты на:

- отсутствие содержимого в приватных логах;
- отклонение внешних endpoint;
- отсутствие скрытой истории;
- удаление временных файлов;
- сохранение прежнего поведения диктовки.

Не добавляйте в issues, логи и тесты реальные разговоры, секреты, токены или содержимое приватных проектов.
