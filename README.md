# Jarvis Voice

**Приватная офлайн-диктовка и локальный голосовой помощник для Claude Code и любого текстового поля.** Скажи «Джарвис», продиктуй мысль, скажи «конец» — текст появится в активном окне. А если начать фразу со «спроси», ответит локальная модель Ollama.

## Зачем

Проект помогает диктовать промты и обычный текст, не переключаясь между мыслью и клавиатурой. Jarvis работает в фоне: после вставки он не завершается, а снова ждёт wake word.

Главное ограничение проекта — **приватность по умолчанию**. Облачное распознавание, внешние AI API, аналитика и скрытая история не используются.

## Возможности

- **Офлайн-распознавание русской речи** через [Vosk](https://github.com/alphacep/vosk-api).
- **Непрерывная диктовка:** один запуск — сколько угодно команд и вставок.
- **Естественная русская озвучка Silero**, с Piper и системными голосами как fallback.
- **Локальный собеседник через Ollama** по команде «спроси».
- **Простая пунктуация:** заглавная буква и завершающий знак без переписывания смысла.
- **Вставка в активное окно** через `Cmd+V` или `Ctrl+V`.
- **Паузы без таймаута:** запись заканчивается только командой «конец».
- **Приватные логи:** распознанный текст по умолчанию не выводится в терминал.
- **Тесты без микрофона:** команды, вставка, озвучка, пунктуация и приватность проверяются отдельно.

## Голосовые команды

| Команда | Действие |
| --- | --- |
| **«Джарвис»** | Озвучить приветствие и начать запись |
| **«конец»** | Вставить распознанный текст и снова ждать «Джарвис» |
| **«спроси …»** после «Джарвис» | Ответить через локальную Ollama, не вставляя вопрос в активное окно |
| **«пока Джарвис»** | Сказать «Хороших выходных, Сэр» и полностью остановить приложение |
| **Ctrl+C** | Остановить приложение из терминала |

По умолчанию приветствие: **«Здравствуйте, Сын Пелея»**. Полное приветствие звучит только после первого «Джарвис» за запуск; при последующих командах Jarvis коротко отвечает **«Слушаю»**.

## Приватность

| Данные | Как обрабатываются |
| --- | --- |
| Аудио | Передаётся только в локальный Vosk, не сохраняется |
| Обычная диктовка | Вставляется в активное окно, наружу не отправляется |
| Вопросы «спроси» | Отправляются только в Ollama на `127.0.0.1:11434` |
| История диалога | Не ведётся; каждый запрос независим |
| Временная озвучка | WAV удаляется сразу после проигрывания |
| Логи | По умолчанию содержат статусы, но не распознанный текст |

Постоянные правила обработки данных и требования к будущим изменениям зафиксированы в [PRIVACY.md](PRIVACY.md).

Ollama endpoint намеренно ограничен локальным адресом: внешний URL клиент отклоняет. Claude Code сам по себе может использовать облачные сервисы Anthropic, но **Jarvis не передаёт туда текст сам** — вставленный дальше текст отправляешь ты.

Приватный режим включён по умолчанию. Чтобы видеть распознанный текст и ответы в терминале:

```sh
JARVIS_PRIVATE_MODE=false ./run.sh
```

## Требования

Для диктовки:

- Python 3.10+; рекомендуется Python 3.12.
- Микрофон.
- Интернет во время установки для зависимостей и моделей.
- Разрешение на микрофон и эмуляцию вставки в активное окно.

Для локальных ответов дополнительно нужны [Ollama](https://ollama.com) и скачанная модель. Диктовка работает без Ollama.

## Быстрый старт

### macOS

```sh
git clone https://github.com/memph11s/jarvis-voice.git
cd jarvis-voice
./setup.sh
./run.sh
```

Если `python3` ссылается на старую версию:

```sh
PYTHON=/opt/homebrew/opt/python@3.12/bin/python3 ./setup.sh
```

В `System Settings → Privacy & Security` выдай терминалу или VS Code:

- **Microphone** — для записи речи;
- **Accessibility** — для эмуляции `Cmd+V`.

Если Jarvis запущен из Terminal или iTerm, Accessibility нужен **именно Terminal/iTerm**, а не только VS Code. После изменения разрешений перезапусти терминал и Jarvis.

### Windows

В PowerShell:

```powershell
git clone https://github.com/memph11s/jarvis-voice.git
cd jarvis-voice
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
.\run.ps1
```

Если Python запускается через Python Launcher:

```powershell
.\setup.ps1 -Python "py"
```

Включи доступ к микрофону для классических приложений в `Settings → Privacy & security → Microphone`. Вставка использует `System.Windows.Forms.SendKeys`.

### Linux

Debian/Ubuntu с X11:

```sh
sudo apt install python3 python3-venv libportaudio2 xclip xdotool pulseaudio-utils alsa-utils speech-dispatcher espeak
git clone https://github.com/memph11s/jarvis-voice.git
cd jarvis-voice
./setup.sh
./run.sh
```

Для Wayland замени `xclip` и `xdotool` на `wl-clipboard` и `ydotool`:

```sh
sudo apt install python3 python3-venv libportaudio2 wl-clipboard ydotool pulseaudio-utils alsa-utils speech-dispatcher espeak
```

`ydotoold` должен быть запущен и доступен пользователю. При установленном `WAYLAND_DISPLAY` приложение использует `ydotool`, иначе — `xdotool`.

## Локальный помощник через Ollama

Установи модель, если её ещё нет:

```sh
ollama pull qwen3:4b
```

Ollama должна быть запущена. Проверить список локальных моделей:

```sh
ollama list
```

Использование:

1. Скажи **«Джарвис»**.
2. После приветствия скажи, например: **«спроси, как устроен протокол HTTP»**.
3. Скажи **«конец»**.
4. Jarvis получит ответ от локальной модели и озвучит его. Вопрос в активное окно не вставляется.

По умолчанию используется общая модель **Qwen3 4B**, а не специализированная кодовая. Другую модель можно выбрать переменной окружения:

```sh
JARVIS_OLLAMA_MODEL="qwen3:4b" ./run.sh
```

Если Ollama недоступна, обычная диктовка продолжает работать.

## Использование для диктовки

1. Поставь курсор в поле ввода Claude Code или другого приложения.
2. Скажи **«Джарвис»** и дождись приветствия.
3. Диктуй текст сколько нужно; паузы запись не завершают.
4. Скажи **«конец»** — текст будет вставлен в активное окно.
5. Для следующей фразы повтори команды без перезапуска.

Jarvis не открывает и не переключает приложения. Перед командой «конец» нужное окно должно быть активным. Для вставки используется системный буфер обмена, поэтому его предыдущее содержимое заменяется.

## Озвучка

По умолчанию используется локальная русская модель **Silero `v5_6_ru`** с голосом `eugene` и sample rate 48 kHz. Она скачивается установочными скриптами и работает без сети. Другие доступные голоса: `aidar`, `baya`, `kseniya`, `xenia`.

Сменить голос:

```sh
JARVIS_SILERO_SPEAKER="baya" ./run.sh
```

Если Silero недоступна, используется **Piper `ru_RU-dmitri-medium`**, затем системные голоса:

- **macOS:** `say`, по умолчанию `Lesya`.
- **Windows:** `System.Speech`.
- **Linux:** `spd-say` или `espeak`; без синтезатора — обычный сигнал.

Изменить приветствие:

```sh
JARVIS_GREETING="Здравствуйте, я слушаю" ./run.sh
```

Изменить прощание:

```sh
JARVIS_FAREWELL="До встречи, Сэр" ./run.sh
```

Выбрать системную голосовую macOS:

```sh
JARVIS_VOICE="Milena" ./run.sh
```

Аудио во время приветствия и ответов отбрасывается, чтобы собственный голос Jarvis не попадал в распознанный текст.

## Как устроен проект

```text
jarvis_voice/
  app.py             # микрофон, команды и жизненный цикл
  session.py         # состояние записи и голосовые команды
  text_processing.py # пунктуация и команда «спроси»
  ollama_client.py   # только локальный Ollama endpoint
  silero_tts.py      # естественная русская озвучка
  piper_tts.py       # fallback-озвучка Piper
  platform_io.py     # системная озвучка, буфер и вставка
run.py               # точка входа
setup.sh             # установка macOS/Linux
setup.ps1            # установка Windows
tests/               # тесты без микрофона и внешних API
```

Русская модель `vosk-model-small-ru-0.22` скачивается с [зеркала Hugging Face](https://huggingface.co/Derur/vosk-models/tree/main/stt/ru/vosk-model-small-ru-0.22), Piper — из [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices), Silero — с [официального сайта моделей](https://models.silero.ai). Модели не включаются в репозиторий.

## Разработка и тесты

macOS/Linux:

```sh
.venv/bin/python -m unittest discover -s tests -t . -v
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
```

Тесты используют поддельные распознаватели и не требуют модель, микрофон или системные разрешения. Сетевая Ollama в тестах заменяется mock-объектом. На текущей машине проверены загрузка моделей, 26 тестов, реальный ответ Qwen3 и озвучка Silero; живой запуск Windows и Linux требует проверки в соответствующем окружении.
